# Border Regression Dataset

## clean
Scans ohne Scannerrahmen oder Schatten.

## black
Scans mit schwarzem Rand (ADF oder Flachbettscanner).

## gray
Scans mit grauem Schatten oder leichtem Rand.

## skew
Schief eingezogene Seiten mit Rand.

Jeder Ordner sollte später mindestens 5 Test-PDFs enthalten.
